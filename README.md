# Furyz

Furyz is a modern e-commerce website built with React and Vite.  
It provides a smooth shopping experience with product browsing, cart management, discounts, likes, blog pages, user authentication, and profile handling.

## Features

- Product browsing and listing
- Shopping cart management
- Discount system
- Like / favorite products
- User login and authentication
- User profile page
- Blog section
- Responsive design
- Component-based architecture
- Modular project structure

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- PostCSS
- ESLint
- npm
